# CampusHire — College Placement Management

Static frontend built with only HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included modules
- Dashboard / placement analytics
- Student Eligibility Engine
- Company Management
- Placement Drive Management
- Application Screening
- Interview Scheduling
- Selection Pipeline
- Placement Analytics
- Job Criteria
- Settings

The forms, filters, navigation, search notifications and dashboard interactions are frontend-only demo behavior. No backend/database is used.
